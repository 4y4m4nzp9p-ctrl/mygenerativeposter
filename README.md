# Kinetic Dance Generative Poster

Week 5 — Arts and Advanced Big Data

This project turns a Python generative-art sketch into an interactive
Streamlit web application.

## Files

- `app.py` — main Streamlit application
- `requirements.txt` — Python packages required by the app

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Controls

- Layers: number of organic forms
- Wobble: irregularity of the forms
- Palette mode: pastel / vivid / mono / random
- Motion: amount of directional movement in the composition
- Seed: reproducible random result

The project follows the Week 5 workflow:
Colab-style generative code → GitHub repository → Streamlit web app.
